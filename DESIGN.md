# Portfolio identity

The public portfolio is an experience of real work: warm paper #fbf8f2, charcoal #211f1b, restrained copper #97412c. Headings use local Space Grotesk, body uses local Sarabun. Real production screenshots carry the project gallery. One full-width featured project leads into a two-column gallery, collapsing to one column on mobile. No hover-only previews or autoplay carousel.

Shared navigation, footer, accessible focus and tokens connect the homepage, work, credentials, contact and case studies. Operational demos retain their useful controls with the same warm palette. Website work and analytics both belong in the introduction. Client claims remain evidence-based; no invented business results.

The badge remains an independent transparent, fixed-length pendulum using the user's genuine photograph. Its face must never be regenerated. Motion is understated and honors reduced-motion preferences.
